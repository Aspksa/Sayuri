# SAYURI BEYOND Animation Engine 4.4

## Назначение

Animation Engine 4.4 позволяет SAYURI BEYOND использовать реальные покадровые PNG-анимации вместо только CSS-движения одного изображения.

Пакет устанавливается локально через окно настроек SAYURI BEYOND и не сохраняется в GitHub. Если пакет отсутствует или для текущего состояния нет кадров, интерфейс автоматически использует обычный портрет/полный PNG и CSS-анимацию как fallback.

## Формат ZIP

Корень архива может содержать только папки состояний и необязательный README.txt.

```
sayuri-animation.zip
├─ idle/
│  ├─ 001.png
│  ├─ 002.png
│  └─ ...
├─ walk/
│  ├─ 001.png
│  └─ ...
├─ think/
├─ read/
├─ work/
├─ happy/
├─ attention/
├─ sleep/
└─ README.txt
```

Поддерживаемые состояния:

- idle — спокойное ожидание;
- walk — движение по интерфейсу;
- think — reasoning, verification, linking;
- read — чтение, изучение, исследование, запоминание;
- work — выполнение задачи;
- happy — успешное завершение и позитивное событие;
- attention — ошибка, противоречие, потеря связи;
- sleep — длительное бездействие.

Имена кадров должны иметь вид 001.png, 002.png, 003.png и т. д. При установке сервер нормализует фактическую нумерацию в непрерывную последовательность.

## Ограничения

- PNG: от 128×128 до 4096×4096.
- До 9 МБ на один кадр.
- До 24 кадров на одно состояние.
- До 96 кадров в одном пакете.
- ZIP до 40 МБ.
- Распакованный набор до 80 МБ.
- Пути с .., абсолютные пути и неизвестные файлы отклоняются.

## Частота кадров

| Состояние | FPS |
|---|---:|
| idle | 4 |
| walk | 10 |
| think | 6 |
| read | 6 |
| work | 8 |
| happy | 10 |
| attention | 10 |
| sleep | 3 |

## Переходы

Движок переключает состояния из реальных событий интерфейса и runtime-статуса. Между кадрами используются два визуальных слоя с коротким crossfade. При движении персонаж автоматически разворачивается в сторону перемещения.

Покадровая анимация используется в режимах полного персонажа. Компактный режим сохраняет портрет и существующий fallback.

## Режим сна

Если Саюри находится в состоянии ready, пользователь долго не взаимодействует с интерфейсом и выбран режим поведения, допускающий ожидание, через 90 секунд может включиться sleep. Любое взаимодействие пользователя возвращает персонажа к актуальному runtime-состоянию.

## Доступность

При системной настройке prefers-reduced-motion автономное перемещение ограничивается, а CSS-анимации и переходы отключаются. При отсутствии покадрового пакета функциональность SAYURI BEYOND сохраняется.
