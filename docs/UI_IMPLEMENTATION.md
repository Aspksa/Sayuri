# Sayuri Kitsune sidebar — UI contract v1.0

Источник требований: [SAYURI_MENU_UI_SPEC.json](SAYURI_MENU_UI_SPEC.json).
Разметка: `web/index.html`; навигация, взаимодействие и телеметрия:
`web/sidebar.js`; backend: `server/runtime.py` и `server/app.py`.

## Точная геометрия и стиль

| Устройство | Параметры |
| --- | --- |
| 1024+ | Панель 280px, свёрнутая 72px |
| 768–1023 | Панель 260px, свёрнутая 72px |
| До 767 | Drawer `min(88vw,320px)`, подложка `rgba(0,0,0,.55)` |
| Все | Высота 100dvh; верх профиля и низ обновлений закреплены; середина прокручивается |
| Доступность | Enter/Space для независимых `details`, Tab-фокус внутри мобильного drawer, Escape/backdrop закрывают и возвращают фокус |
| Цвета | Все основные токены строго из JSON, включая `#11121B`, `#1D1E2B`, `#272838`, `#F1ACD2`, `#DCA5F4` |
| Анимация | `prefers-reduced-motion` отключает движение и плавные переходы |

Навигация: **Sayuri Kitsune / Личный кабинет**, раскрывающиеся «Состояние Саюри», «Сеть и сервер», «Cloud.ru AI», «Единый чат», «Рабочие проекты», «Документы / Облако / Sayuri», «Домашние проекты» и снизу «Обновление проекта». Неиспользуемые права и память не расширены.

## Источник истины — сервер

Обычные API:
- `GET /api/runtime/status` — авторизованный REST-снимок.
- `GET /api/runtime/events` — авторизованный SSE, уведомления при реальном событии, heartbeat ~20 секунд.
- Если SSE недоступен, веб-клиент использует REST с интервалом 20 секунд и переподключается с экспоненциальной задержкой и jitter. Если снимок старше 65 секунд, «Нет свежих данных».
- Не передаются тексты диалогов, документы, API-ключи, заголовки Authorization или stack traces.

**Состояние Саюри:** `ready` при здоровом backend и отсутствии работы; `reasoning` только при фактическом запросе Cloud.ru; `studying` при явном анализе чата; `researching` при поиске по локальным документам; `verifying` при фактической проверке наставника; `memorizing` при записи в память; `completed`/ `attention` при исходе операции. `linking` и часть задач не выдаются за действующие процессы: граф знаний и агентный runtime ещё не реализованы. Все двенадцать подписей существуют в справочнике; активная индикация — только по событиям.

**Сеть и сервер:** backend определяется только по доступности локального API. Внешняя связь определяется отдельным серверным запросом `HEAD https://github.com/` с таймаутом и интервалом примерно 25 секунд (это проверка доступности GitHub, **не** безусловное утверждение о всём интернете). Задержки backend и внешнего запроса измеряются раздельно.

**Cloud.ru:** авторизованная серверная проверка `/models` каждые ~30 секунд при заданном ключе и модели. Идентификатор модели проверяется по **реальному** каталогу аккаунта; если его нет, состояние `degraded`, а не ложное «Подключено». Ошибки 401/403, 402, 429, 5xx и таймауты различаются. Число запросов и токены берутся из реальных запросов и ответа провайдера, тариф **не выводится** без проверенной цены; `cost_rub=null`.

**Не реализованы:** граф знаний, полноценное изучение PDF, обработка произвольных файлов, модель самостоятельного обучения и полноценная WebSocket-инфраструктура. Соответствующие статусы не симулируются.

## Проверки

- `python -m pytest -q` — авторизация SSE, реальные операции, API Cloud.ru, совпадение статусов с JSON, WCAG AA-контраст и сохранение старых функций.
- `node --check web/app.js && node --check web/sidebar.js` — синтаксис.
- `python tests/ui_smoke.py` — Chromium: экраны 360, 390, 768, 1024 и 1440px, профиль, свёртывание до 72px, Escape, сохранение фокуса, закреплённый footer.
- В GitHub Actions есть задания `python` и `browser`.

## Обновление вашей ZIP-версии

В кабинете / нижней кнопке «Обновление проекта» запустите «Проверить обновления» → «Скачать ZIP-обновление». Создаётся новая папка рядом со старой; `.env` и локальная `data/` копируются, SQLite копируется согласованно. Старую рабочую папку не удаляйте до проверки новой версии.
