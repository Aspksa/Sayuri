# Sayuri roadmap

Core: Python/FastAPI. Storage: SQLite. Model provider: Cloud.ru via server-side API key. Persona: `config/persona`. Chat: authenticated website and Flutter client.

Implemented: chat history, user-defined memory, model responses, feedback, locally stored files. Not yet implemented: automatic memory extraction, vector/RAG, Cloud.ru teacher, model finetuning, shared mobile account panel, cloud folder integrations and automatic GitHub updates. Public deployments require HTTPS, stronger rate limits, backup and security review.
