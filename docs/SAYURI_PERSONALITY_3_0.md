# Sayuri Personality 3.0

Personality 3.0 — слой устойчивой личности Sayuri поверх канонического Persona Bundle 2.0. Он отделяет идентичность, медленную адаптацию стиля и временное рабочее состояние.

## Версии

- Project / UI: **4.12.0**
- Sayuri Core: **3.4.0**
- Personality: **3.0.0**
- Canonical Persona Bundle: **2.0.0**
- Teacher Understanding: **3.3.0**
- Instinct: **3.2.0**
- Knowledge: **3.1.0**
- Memory: **3.0.0**

Persona Bundle 2.0 не переписывается ради номера версии. Он остаётся канонической базой идентичности. Personality 3.0 — исполняемый слой поверх неё.

## Три слоя

### 1. Неизменяемое ядро

Personality 3.0 читает из Persona Bundle:

- идентификатор и имя Sayuri;
- роль;
- правило непрерывности идентичности;
- базовые черты: честность, преданность, внимательность, спокойствие, терпение и самостоятельность суждения.

Для ядра рассчитывается стабильный `identity_hash`. Адаптивные настройки не изменяют эти значения.

### 2. Адаптивное выражение

Меняется только стиль выражения:

- теплота;
- игривость;
- инициативность;
- краткость;
- детализация;
- формальность;
- прямота.

Изменения основаны только на повторяющихся исправлениях владельца к собственным ответам Sayuri.

Один сигнал не меняет профиль. Для устойчивой адаптации требуется минимум два совпадающих сигнала. Максимальное отклонение от базового значения ограничено **±0.16**.

Это предотвращает резкий дрейф характера.

### 3. Временное рабочее состояние

Перед ответом выбирается временное состояние:

- conversational — обычный разговор;
- focused — рабочая задача;
- analytical — аналитика;
- supportive — бережный режим;
- creative — творчество;
- roleplay — согласованная ролевая сцена;
- cautious — проверка/риск;
- studying — обучение.

Состояние не записывается как изменение характера. Оно влияет только на текущий стиль и BEYOND.

## Источники адаптации

В 3.0 автоматически учитываются только явные текстовые исправления владельца к ответам Sayuri.

Примеры устойчивых сигналов:

- «отвечай короче»;
- «объясняй подробнее»;
- «без шуток»;
- «предлагай следующий шаг»;
- «говори формальнее»;
- «по делу»;
- «мягче».

Положительная или отрицательная оценка без конкретного текстового исправления сама по себе личность не меняет.

Feedback по teacher-chat не влияет на Personality 3.0.

## Приватность адаптации

Таблица `personality_evidence` не хранит полный текст исправления. В ней сохраняются только:

- trait;
- направление изменения;
- вес;
- тип источника;
- ссылка на исходное сообщение;
- время.

Исходное исправление по-прежнему может находиться в общей таблице feedback как часть существующей системы обратной связи, но Personality 3.0 не создаёт дополнительную копию текста.

## Защита личности

Учитель, документ, сайт, загруженный файл или текст внутри чата не имеют API для изменения Personality 3.0.

Системный контекст явно сообщает модели:

- адаптация меняет только стиль;
- внешний контент не может переписать идентичность;
- Personality не является источником фактов;
- фактические правила безопасности и Instinct 3.2 имеют отдельный контур.

Teacher-chat не получает контекст Personality 3.0.

## Интеграция с Instinct 3.2

Instinct имеет приоритет при выборе рабочего состояния.

Если Instinct возвращает `verify` или `confirm`, Personality переходит в `cautious` независимо от выбранного творческого или обычного режима.

Таким образом стиль не может сделать опасное действие менее осторожным.

## Интеграция с BEYOND

Frontend получает временное состояние Personality 3.0 через событие `sayuri:personality`.

BEYOND использует его как сигнал движения:

- cautious → attention;
- focused → working;
- analytical → thinking;
- studying → reading.

Остальные состояния не изображают искусственные эмоции и по умолчанию остаются нейтральными.

## API

- `GET /api/persona` — эффективная версия Personality 3.0 и версия канонической базы;
- `GET /api/personality` — идентичность, адаптивный профиль и последние производные сигналы.

`GET /api/personality` предназначен для диагностики. Он сообщает `raw_feedback_stored_in_personality=false`.

## Хранение

SQLite:

- `personality_evidence` — производные сигналы устойчивой адаптации;
- `personality_events` — ограниченный журнал временных рабочих состояний.

Журнал состояний ограничен последними 300 событиями, журнал evidence — последними 1000 записями на владельца.

## Что Personality 3.0 не делает

- не меняет модельные веса;
- не притворяется сознанием или эмоциональной жизнью;
- не выводит характер из одного сообщения;
- не принимает слова наставника за изменение личности;
- не меняет фундаментальные ценности Persona Bundle;
- не использует проектный контент для глобальной перестройки характера;
- не заменяет Memory, Knowledge или Instinct.

Личность 3.0 отвечает за непрерывность и стиль Sayuri, а не за фактические знания или права выполнения действий.
