# Sayuri — Понимание учителя 3.3

Понимание учителя 3.3 — автоматический слой Sayuri Core, который разбирает объяснения отдельного ИИ-наставника, проверяет собственное понимание Sayuri и при необходимости самостоятельно задаёт наставнику уточняющие вопросы.

## Версии

- Проект / UI: **4.11.0**
- Sayuri Core: **3.3.0**
- Понимание учителя: **3.3.0**
- Инстинкт: **3.2.0**
- Знания: **3.1.0**
- Память: **3.0.0**
- Личность: **2.0.0**

## Автоматический цикл

После каждого обычного ответа в teacher-chat Sayuri запускает фоновый цикл:

1. анализирует вопрос владельца и ответ наставника;
2. определяет тему урока;
3. выделяет понятия, утверждения, примеры и методы;
4. фиксирует непонятые места;
5. оценивает уверенность понимания;
6. если понимание недостаточно — формулирует один уточняющий вопрос;
7. сама отправляет этот вопрос модели-наставнику;
8. получает дополнительное объяснение;
9. повторно анализирует весь урок с учётом уточнения;
10. при необходимости делает второй и последний уточняющий раунд.

Максимум — **2 автоматических уточняющих вопроса на один исходный обмен**. Это жёсткое ограничение предотвращает бесконечный цикл и неконтролируемое количество запросов.

## Когда урок считается понятым

Урок получает статус `understood`, только если:

- анализатор не оставил существенных пунктов `unclear`;
- модель явно указала `understood=true`;
- confidence не ниже 0.72.

Если после двух уточнений понимание всё ещё недостаточно, урок сохраняется как `partial`.

Если внешний вызов или разбор JSON завершился ошибкой, урок получает статус `error`, но уже завершившийся разговор владельца с наставником не ломается.

## Что сохраняется

Каждый урок хранит:

- исходный вопрос владельца;
- исходный ответ наставника;
- проектный контекст, если он был активен;
- тему;
- краткое резюме;
- понятия и их объяснения;
- утверждения наставника;
- примеры;
- методы;
- непонятые места;
- оценку уверенности;
- статус понимания;
- число уточняющих раундов.

Каждый автоматический вопрос Sayuri и ответ наставника сохраняются отдельно в истории урока.

## Важная граница доверия

Слова наставника **не становятся автоматически подтверждёнными фактами** Memory 3.0 или Knowledge 3.1.

Понятый урок используется как отдельный источник:

> «Уроки учителя 3.3 — материал, который Sayuri поняла из объяснений наставника; это источник для рассуждения, но не подтверждённый факт».

То есть система различает:

- «учитель это сказал»;
- «Sayuri поняла, что он имел в виду»;
- «это подтверждённый факт».

Это три разные вещи.

## Использование в будущих ответах

Sayuri может локально подобрать релевантный понятый урок по словам текущего вопроса и добавить его в собственный контекст как непроверенный источник учителя.

Уроки учитывают `project_id`: если урок был получен внутри проекта Alpha, он не подмешивается в проект Beta.

Глобальные уроки без проекта могут использоваться в любом проекте.

## Работа моделей

Для анализа понимания используется модель Sayuri из `CLOUD_RU_MODEL`.

Если отдельная модель Sayuri не настроена, анализ временно выполняется моделью наставника, чтобы автоматический цикл не прекращался.

Уточняющий ответ всегда запрашивается у `CLOUD_RU_TEACHER_MODEL`.

Внутренние уточняющие вопросы не записываются в обычную историю чата как сообщения владельца. Они хранятся в таблицах уроков, поэтому не искажают историю разговора пользователя.

## Память владельца

Анализатор может выделить до трёх устойчивых фактов, которые **явно сообщил сам владелец**.

Они не записываются в Memory 3.0 автоматически. Как и раньше, они создаются только как `memory_candidates` и требуют подтверждения владельца.

Слова наставника в такие кандидаты попадать не должны.

## Хранение

SQLite:

- `teacher_lessons` — состояние и итог понимания урока;
- `teacher_lesson_turns` — автоматические уточняющие вопросы Sayuri и ответы наставника.

## API диагностики

Отдельного кабинета для функции нет.

Для диагностики и тестов доступны:

- `GET /api/learning/lessons`
- `GET /api/learning/lessons/summary`
- `GET /api/learning/lessons/{lesson_id}`

Обычная работа полностью автоматическая.

## Ограничения 3.3

«Понимание» оценивается моделью Sayuri и не является математическим доказательством усвоения.

Версия 3.3 пока не проводит отдельный экзамен по каждому уроку и не строит полноценную педагогическую модель навыков. Она проверяет структурную полноту объяснения, неопределённость и способность Sayuri сформулировать оставшийся вопрос.

Следующий возможный этап — проверка усвоения через самотестирование: Sayuri формулирует контрольные вопросы сама себе, отвечает без помощи наставника и только затем оценивает, действительно ли материал усвоен.
