# Sayuri Persona v2.0.0 — интеграция

**Источник:** загруженный авторский файл `SAYURI_PERSONA_RU_v2.0.0.json` (UTF-8).

Профиль импортирован в репозиторий как **18 последовательных исходных частей** в `config/persona/v2_parts/part_*.txt`: такое представление сохраняет полный JSON и позволяет обойти ограничение на размер одной GitHub-записи. Модуль `server/persona.py` собирает его без потерь в памяти, выполняет `json.loads` и проверяет важные счётчики. Никакие части или диалоги не передаются в базу реальных разговоров.

Чтобы получить обычный единый файл **после обновления GitHub**, выполните из корня проекта:

```bash
.venv/Scripts/python.exe -m server.persona
```

Будет создан `config/persona/SAYURI_PERSONA_RU_v2.0.0.json` — с тем же содержимым в формате JSON. Это не нужно для работы чата; загрузчик самостоятельно читает исходные части.

## Проверенная структура

- 55 разделов верхнего уровня
- 100 синтетических диалогов / 540 сообщений
- 400 примерных реплик в 50 категориях
- 60 правил поведения и 60 проверочных сценариев
- 9 глав легенды и 18 ритуалов
- Полная и компактная системные инструкции для генерации ответов
- Фиксация вкусов, характера, памяти, обещаний, инициативности, дневника опыта, голоса, мимики и анимации

**Состояние функций.** Профиль — спецификация персонажа. Не все описанные механизмы выполняются приложением: голос, магия, автоматические поручения, уведомления и изменение весов модели требуют отдельных реализаций. Девять хвостов и магические способности относятся к художественной легенде. Реальное обучение пока основано на подтверждённой памяти, а не на дообучении нейросети.

Системный текст берётся из `prompt_templates.system_prompt_ru` в профиле версии 2.0; режимы — из `prompt_templates.mode_overrides_ru`. В текущем общем чате отвечает **наставник**, а Саюри наблюдает за ним. Системный характер Саюри используется при собственных ответах, а не для переписывания личности наставника.
