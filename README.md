# Sayuri 0.1 — облачная кицунэ-помощница

Единый проект: **FastAPI + SQLite + Cloud.ru Foundation Models + адаптивный веб-чат**. Собственная локальная модель **не используется**. Cloud.ru вызывается **только сервером**; API-ключ не передаётся браузеру или мобильному приложению.

## Windows
1. Установите Python 3.10+.
2. Запустите `Sayuri.bat`.
3. Откройте http://127.0.0.1:8765 и создайте пароль владельца (минимум 12 символов).
4. Для ответа модели заполните **CLOUD_RU_API_KEY**, **CLOUD_RU_BASE_URL** и **CLOUD_RU_MODEL** в закрытом `.env`, затем перезапустите программу.
5. Данные по умолчанию хранятся в `data/` (вне Git); для постоянного пути укажите **SAYURI_DATA_DIR**.

**Cloud.ru API**: сервер ожидает OpenAI-совместимый endpoint `<CLOUD_RU_BASE_URL>/chat/completions` с Bearer API-ключом и полями `model`/`messages`. Уточните актуальные URL и идентификатор модели в своём кабинете Cloud.ru. Ключ никогда не записывайте в репозиторий.

## Состояние реализации
- Регистрация единственного владельца, авторизация, чаты, история, облачные ответы, сохранение явной памяти, отзывы, локальная загрузка документов (без автоматической индексации).
- 30 синтетических диалогов, 100 реплик и персона из `config/persona/`. Образцы не подмешиваются в реальную историю пользователя.
- Мобильная основа Flutter в `mobile/` подключается к тому же API; для доступа с телефона нужен защищённый доступ к серверу (HTTPS), а не просто localhost.
- Добавлен ИИ-наставник: укажите `CLOUD_RU_TEACHER_MODEL` в `.env`, затем в личном кабинете откройте «Изучить текущий чат». Кандидаты фактов записываются в память только после нажатия «Запомнить»; можно отклонить каждое предложение. Есть просмотр датасета обратной связи (не обучение весов). Следующие задачи: векторный поиск/RAG, полноценная обработка документов, регулярное облачное дообучение LoRA с тестированием, уведомления и защищённый удалённый сервер. **Самообучение весов модели сейчас отсутствует**.
- Проверка обновлений GitHub Releases через `updater.py` при запуске: **без автоматической установки**.\n- Доступ к «Рабочим проектам» и «Домашним проектам» — только чтение в пределах каталога, явно заданного через `SAYURI_PROJECTS_DIR`.\n- `Sayuri.bat` запускает Windows-сервер. Запуск с USB-носителя возможен при наличии Python и прав на запись; переносимость файлов не означает доступность облака офлайн.

## Безопасность
Запускайте локально на `127.0.0.1`. Для удалённого сайта и приложения обязательно используйте reverse proxy с HTTPS, ограничения входа, управление устройствами, резервные копии и HTTPS до провайдера. Вложения не отправляются в Cloud.ru автоматически. БД и секреты не попадают в git. Не размещайте сервер напрямую в интернете без дополнительной защиты.

Проверка: `python -m compileall server run.py` и `pytest` после установки зависимостей.

## Cloud.ru
Официальная база URL: `https://foundation-models.api.cloud.ru/v1`.
Задайте `CLOUD_RU_MODEL` из списка моделей, доступных вашему сервисному аккаунту, и секрет в локальном `.env`.
Опционально `CLOUD_RU_TEACHER_MODEL` позволяет отдельно анализировать чаты и **предлагать** подтверждаемую память. Сведения не записываются наставником автоматически. В кабинете доступны оценки ответов и предпросмотр примеров для будущего датасета; веса модели **не дообучаются**.

## Рабочие и домашние проекты
При необходимости укажите `SAYURI_PROJECTS_DIR=C:/Users/USERNAME/Documents/Облако/Sayuri` в своём `.env`.
Разместите внутри две папки: `Рабочие проекты` и `Домашние проекты`. В разделе «Документы» появятся доступные файлы с ограничением области просмотра; файлы не передаются модели без отдельного действия. Отсутствующий путь означает отсутствие доступа. Для любых удалённых устройств необходим защищённый HTTPS-сервер с авторизацией.

## Обновления
`Sayuri.bat` проверяет наличие опубликованного релиза GitHub без принудительной установки. Резервное копирование и атомарная проверенная установка релизов — отдельный этап. Файл `updater.py` не исполняет удалённые скрипты.

## Ограничения прототипа
Для Cloud.ru нужно подтвердить настоящий URL API и ID доступных моделей в кабинете поставщика. Проект не отправляет ключ из браузера/мобильного клиента. Публикация сервера в интернете без HTTPS, защиты входа от перебора, резервного копирования и аудита запрещена. Flutter содержит исходники, а не готовые APK/IPA. GitHub Releases пока только проверяются, не устанавливаются. Реального обучения весов модели нет.

## Дополнительные возможности
- `Sayuri-backup.bat` — архив базы данных и вложений в `data/backups/` или `SAYURI_DATA_DIR/backups/`. Архив не зашифрован: храните его отдельно и защищённо.
- Личный кабинет позволяет выбрать режим речи и уровень нежности, добавить/удалить подтверждённые факты, проверить предложения ИИ-наставника и посмотреть модели Cloud.ru.
- PWA: в мобильном браузере можно установить сайт на домашний экран через меню браузера. Работа с облачной моделью и историей требует доступного сервера.
- Прочитайте [инструкцию подключения Cloud.ru](docs/CLOUD_RU.md) и [архитектуру](docs/ARCHITECTURE.md).
- Загруженные документы и диалоги можно удалить из интерфейса. Старые резервные копии при этом не удаляются автоматически.
